Our principle is: Excel in, Excel out. The social workers drop in the exports exactly as the system produces them – German column names, Swiss dates. The tool recognises each file by its columns, not by its file name, and writes a data-quality report. Then it applies the rules for deadlines and the three goals. Every assumption we had to make is in one readable file, so the ASD can change it without a programmer. And the result comes back as Excel, so it fits their daily work.
