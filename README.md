# Integrations-Cockpit

**From Excel exports to "who do I call this week".**

A hackathon prototype for the Asylsozialdienst (ASD) of the City of Bern. The service is
paid when a refugee reaches an integration goal on time: language, work, financial
independence. Nobody can see today who is on track. The cockpit reads the Excel
exports the service already has and shows exactly that, per person and per household.

## What it does

**Level 1: where does each client stand?**

| Goal | Rule |
|---|---|
| 1 · Language A1 | A1 in German or French within 3 years of entry (VA/FL, aged 16+) |
| 2 · Work / training | 6 months in a row at ≥ 60 % employment, or secondary II / tertiary education, before responsibility ends |
| 3 · No social assistance | 12 months without Sozialhilfe for the whole household, before responsibility ends |

For every client the cockpit computes each goal's deadline and a traffic light:
🟢 reached · 🟡 on track · 🔴 at risk or missed.

- **Two roles.** *Leitung* (management) sees the whole matrix. *Sozialarbeiter:in* (social
  worker) gets **"Wen rufe ich an?"**: a call list with red cases first, then the nearest
  deadline, each with the reason written out.
- **Data quality.** Every file is recognised by its columns, whatever its name. The tab
  lists what is missing or inconsistent. It also finds money the service is owed: people
  who proved A1 on time but whose goal was never recorded.
- **Excel in, Excel out.** The results download as an Excel workbook for daily work.

**Level 2: why?** The *Muster* tab compares groups of clients who reached a goal on time
with those who did not. It looks at Latin-script literacy, schooling, motivation and
psychological burden. Two safeguards are built in:

- It shows **groups only**: never a single person, and never a group smaller than ten.
- It reports **associations, not causes**. A pattern tells you where to look closer.

**Free-text reports.** Motivation and burden come from the *Situationsanalyse* Word
documents. Before extraction, names, phone numbers, addresses and identifiers are
removed. Two extraction methods are available:

- **Rules:** keyword matching. Fast and easy to trace.
- **Local LLM:** `qwen3:4b` running through [Ollama](https://ollama.com) on the same
  machine. Nothing leaves the network.

The *Situationsanalysen* tab measures each method against a ground truth, which exists
for the synthetic data only.

## Run it

Requires Python 3.12+.

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

Open http://localhost:8501. In the sidebar, choose **Synthetische Demodaten** to explore
the demo, or **Eigene Exporte hochladen** to drop in real exports. The first load takes
about 20 seconds.

Optional, for the LLM extraction:

```powershell
ollama pull qwen3:4b
python -m cockpit.situationsanalyse data/situationsanalysen --methode llm --out data/situationsanalyse_merkmale_llm.xlsx
```

## Assumptions live in `rules.yaml`

Some points the challenge description leaves open, for example:

- at what moment a person must be 16,
- what the `+5` / `+7` status suffix means,
- how the 2027 change from 7 to 5 years applies.

Each of these is a setting in [`rules.yaml`](rules.yaml) with a comment, not a constant
in the code. Once the ASD clarifies one, it can be changed without touching the code.
The *Annahmen* tab in the app shows them all.
